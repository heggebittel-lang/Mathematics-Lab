# Mathematics Lab · 考研数学三自主推导工作台

> 发布状态：V5.4 的源码尚未全部上传。当前仓库仅为发布准备，请勿将当前仓库 ZIP 当作完整可运行版本。

一个可离线运行的考研数学三交互式数学实验室。它不是自动解题网站，而是把数学决策交给学习者，把繁琐的机械运算、表达式整理和结果核验交给软件。

**当前版本：V5.4（公开源码版）** · 2019—2026 年共 178 道题的训练入口。

## 快速开始

1. 在 GitHub 仓库点击 `Code → Download ZIP`，完整解压。
2. 用较新的 Edge、Chrome 或 Firefox 打开 `index.html`，不需要安装 Node.js、登录或联网。
3. 从左侧按知识点或年份选题，在中央选择公式与运算，右侧管理题给对象和推导结果。
4. 自主完成推导，再到「步骤检测」核验，或展开参考解析。证明题采用人工自评。

也可以在源码目录运行 `python -m http.server 8000`，浏览器访问 `http://localhost:8000`。这只是可选的本地静态服务。

> **公开版资料说明：** 为避免擅自再分发授权不明的试卷扫描、培训资料及汇编 PDF，本仓库不包含原卷图片和原资料文档。178 道题的训练入口及代码保留，但部分旧题的完整题面、选项或图形需要对照自备试卷。2026 年题目有结构化题面。可依照 `docs/LOCAL-MATERIALS.md` 自行补齐本地资料，不要将未获授权的材料提交到仓库。

## 为什么做这个项目？

数学复习中，理解公式和决定解题路线，与大量重复计算是两回事。本项目试图减少后者的阻力：可以引用上一条草稿中的函数、矩阵或概率模型继续运算，不必反复抄写；结果与来源关联，修改源对象后旧推导不再被视为有效。

它尤其适合已经学过基本知识，却在计算、公式选择和连续推导上经常卡住的考生。正式考试仍需要纸笔独立计算，建议结合限时真题训练使用。

## 主要功能

| 模块 | 功能 |
| --- | --- |
| 高等数学 | 极限、Taylor 展开、求导、积分、多元极值、微分方程、级数等 |
| 线性代数 | 矩阵运算、行列变换、行列式、秩、线性方程组、二次型等 |
| 概率统计 | 概率模型、期望方差、条件概率、相关系数、参数估计等 |
| 自主推导 | 题给对象复用、精确分数、运算来源追踪、撤销重做 |
| 训练与核验 | 分步检测、参考解析、证明工作台、错步复练 |
| 操作体验 | 专注推导、数学键盘、草稿搜索、唯一有效来源预选 |

## 使用原则

- 先独立决定数学方法，再调用运算；不要把工具输出当作自己掌握知识的证据。
- 检测通过表示对应的可计算条件通过，不等于整份证明正确或达到官方评分标准。
- 不是通用 CAS：部分操作仅支持指定数学结构，尚不能覆盖全部合法等价解法。
- 2026 年大题个别分值为站内暂定；题面和解析可能仍有错误，欢迎指出。

## 反馈与贡献

欢迎在 GitHub 的 **Issues** 中提交错误报告、操作建议或新的合法解法。请尽量提供年份和题号、运算入口、输入及中间对象、预期结果、实际结果、浏览器与版本。

反馈优先级：数学错误 / 推导断点 > 无法复用数学对象 > 不必要的操作步骤 > 界面与其他建议。项目根据实际反馈不定期更新，不承诺固定发布时间。也欢迎通过 Pull Request 提交可复现的修复。

## 开发与测试

静态 HTML、CSS、JavaScript，无后端服务。MathJax 随项目提供，负责离线公式排版。

- `index.html` / `style.css`：工作台界面。
- `core.js`、`algebra.js`、`statistics.js`、`math*.js`：数学内核。
- `content*.js`、`data.js`：题库与公式数据。
- `release*.js`：各批专用交互及运算链。
- `tests/`：Node 数学内核测试；运行 `node tests/run-all.cjs`。
- `docs/`：题源记录、发布说明、本地资料说明。

公开版重新通过 46 个数学内核脚本（309 条 PASS 记录），旧题缺图提示、证明题、2026 结构化题面及本地资料开关通过浏览器抽查。第三方原资料文件存在性检查默认明确跳过，不计为通过。详细见 [公开版验收](docs/PUBLIC-RELEASE.md)。Windows 原生离线环境与全部替代解法仍需实机反馈。
