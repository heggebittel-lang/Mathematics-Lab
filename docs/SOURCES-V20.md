# V2.0 数学三原卷核验
本轮只使用用户上传的《03.2010-2022考研数学三真题.pdf》及其对应原卷裁图，不联网替换题面。逐张查看包内 assets16/2022-10.jpg（物理第3页）、2022-17.jpg（第4页）、2022-20.jpg、2022-21.jpg、2022-22.jpg（第5页）。
- Q10：联合表 x=-1,1，y=0,1,2；各行 (0.1,0.1,b)、(a,0.1,0.1)。max=2 事件包含格(-1,2),(1,2)，min=1 事件包含格(1,1),(1,2)，交集格(1,2)。0.1=(b+0.1)*0.2 得 b=0.4；归一化 a=0.2；EX=-0.2，EY=1.2，E(XY)=-0.6，Cov=-0.36（原卷B）。
- Q17：y′+y/(2√x)=2+√x，y(1)=3。取 p=2x，代回核验；u=y−p 满足 u′+u/(2√x)=0，u=Ce^(−√x)，C=e。y−2x=e^(1−√x)→0，故斜渐近线 y=2x。
- Q20：原系数 [(-4)^n+1]/[4^n(2n+1)]。拆为 q=-1、q=1/4；半径1、2；较小半径的端点交错收敛，另一项绝对收敛。x乘级数后逐项求导为 1/(1+x²)+1/(1−x²/4)。积分得 arctan x+ln((2+x)/(2−x))，再除以x；原级数x=0时为2。端点用 Abel 连续延拓。
- Q21：f=3x₁²+4x₂²+3x₃²+2x₁x₃=2(x₁+x₃)²+(x₁−x₃)²+4x₂²。取 Q 列为 (1,0,1)/√2、(0,1,0)、(1,0,-1)/√2。QᵀQ=I，标准形4y₁²+4y₂²+2y₃²，商不小于2；y₃≠0、y₁=y₂=0 时取等。
- Q22：两组指数均值 θ、2θ，n,m 正整数，S_X=ΣX_i，S_Y=ΣY_j。ℓ=−(n+m)lnθ−m ln2−(S_X+S_Y/2)/θ。得分函数为 [S_X+S_Y/2−(n+m)θ]/θ²，正到负（样本和几乎必然为正）。θ̂=(S_X+S_Y/2)/(n+m)。独立性给 D(S_X)=nθ²、D(S_Y/2)=mθ²，故 D(θ̂)=θ²/(n+m)。
