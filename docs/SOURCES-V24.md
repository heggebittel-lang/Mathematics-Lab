# V2.4 原题及数学核验
题面依据：用户提供《03.2010-2022考研数学三真题.pdf》在V1.6保留的原卷裁图 assets16/2020-17.jpg、2020-23.jpg、2019-17.jpg、2019-18.jpg、2019-22.jpg，逐张直接视觉核对。未用网络题面或其他卷种替换。参考 content16 后独立推导：

- 2020 Q17：y″+2y′+5y=0，f(0)=1,f′(0)=−1。r=−1±2i；C₁=1,C₂=0。原函数 e^(−x)(−cos2x+2sin2x)/5，a_n=e^(−nπ)/5。n 从1起；和 e^(−π)/[5(1−e^(−π))]=1/[5(e^π−1)]。新增原函数系数在内核以求导反验。
- 2019 Q18：x≥0，面积而非带符号积分。每段[kπ,(k+1)π]平移并取绝对值，首段原函数 −e^(−x)(cos x+sin x)/2，首段(1+e^(−π))/2，公比 e^(−π)，从k=0求和。
- 2019 Q17：y′−xy=e^(x²/2)/(2√x)，y(1)=√e。μ=e^(−x²/2)，(μy)′=1/(2√x)，μy=√x+C，C=0。绕x轴，1≤x≤2，V=π∫₁²x e^(x²)dx=π(e⁴−e)/2。
- 2020 Q23：F(t)=1−exp[−(t/θ)^m]（t≥0），θ,m>0。S(t)=exp[−(t/θ)^m]；条件概率 S(s+t)/S(s)。f(t)=(m/θ)(t/θ)^(m−1)S(t)（t>0）；设 u=θ^m、S=Σt_i^m，忽略与u无关项，ℓ=−n ln u−S/u，ℓ′=(S−nu)/u²。S>0时正到负；θ̂=(S/n)^(1/m)。S=0时正尺度上无有限最大值；连续模型下该样本概率为0。似然依赖题意中独立同分布样本。
- 2019 Q22：X~Exp(1)，Y取−1,1且概率p,1−p，独立。Z=XY，负轴密度pe^z，正轴(1−p)e^(−z)。EX=1、EX²=2、EY=1−2p；EZ=EX·EY，E(XZ)=EX²·EY；Cov=1−2p；p=1/2时不相关。X≤1与|Z|≤1为相同事件，概率1−e^(−1)严格介于0与1，故不独立。密度在0处的取值不影响分布。

本轮核验仅上述五题，不是对整个题库的数学审计。
