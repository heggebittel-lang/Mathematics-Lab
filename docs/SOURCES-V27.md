# V2.7 原卷与数学核验
题面依据：用户提供的《03.2010-2022考研数学三真题.pdf》，使用原卷裁图 assets16/2021-04.jpg、2022-07.jpg、2021-09.jpg、2019-09.jpg、2020-04.jpg 逐一视觉核对；未使用网络其他卷种替换。裁图有少量相邻题行，原卷仍保存在 resources。以下为独立推导。

- 2021 Q4：f(x+1,e^x)=x(x+1)^2 在 x=0 求导得到 f_x+f_y=1；f(x,x²)=2x²ln x 在 x=1 得 f_x+2f_y=2，两式同在(1,1)。相减得 f_y=1，回代 f_x=0。C。
- 2022 Q7：A=(α1,α2,α3)，B=(α1,α2,α4)。det A=(λ−1)^2(λ+2)，det B=(λ²−1)^2。λ=1 时两组全为同一非零向量；λ=−1 时 A满秩、B不满秩；λ=−2 时反之。其余均满秩。C。两个行列式由实际三阶展开和内核精确核验，特殊分支秩由有理消元核验（也可纸笔观察）。
- 2021 Q9：每对 W_i=X_i−Y_i，EW=μ1−μ2；DW=σ1²+σ2²−2ρσ1σ2。不同样本对独立，D(平均)=DW/n。B。内部 a,b,s,t,r 对应 μ1,μ2,σ1,σ2,ρ，公式显示转换。
- 2019 Q9：1/[k(k+1)]=1/k−1/(k+1)，相消后底数 n/(n+1)，n次幂=(1+1/n)^(-n)→e^(-1)。
- 2020 Q4：原中心2半径4；n^(1/n)→1，不改变去掉 n 后的半径。令 u=(x+1)²，|u|<4 得 −3<x<1。题问收敛区间，端点是否收敛不能由题给条件确定。B。
