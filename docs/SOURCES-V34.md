# V3.4 原题与数学核验
本轮核对原上传卷的实际页面图，未替换题面，也未借用其他卷种。

- 2023 Q18：`assets06/exam23-04.jpg`（《2023数学三真题.pdf》对应页面）。0≤y≤1/(x√(1+x²)), x≥1。面积积分以 t=1/x 换元，dx=−dt/t²，因 t>0，√(1+x²)=√(1+t²)/t，得到 ∫₀¹dt/√(1+t²)=ln(1+√2)。圆盘法 V=π∫₁^∞dx/[x²(1+x²)]；输入 a=1,b=−1 的分式系数，经通分核验，分别计算 ∫₁^∞dx/x²=1 和 −∫₁^∞dx/(1+x²)=−π/4，得到 π(1−π/4)。对数型原函数由公式选用，端点实际代入；圆盘反正切使用精确特殊端点，不是通用符号积分。
- 2024 Q17：`assets06/exam24-03.jpg`（《2024考研数学（三）真题.docx》对应转图）。第一象限 xy∈[1/3,3]、y/x∈[1/3,3]。交换 x,y 后积不变、比值取倒数，区域不变，故 f(x,y)=1+x−y 的对称平均为1。选择 u=xy,v=y/x，逆映射 x=√(u/v),y=√(uv) 为正，实际偏导得 J=y/x−x(−y/x²)=2y/x=2v；面积因子1/(2v)。新矩形两区间均[1/3,3]，先积分 u 后得到 4/(3v)，再积分 v 得 (4/3)ln9=(8/3)ln3。当前只实现此坐标族及先积u；不等于支持任意二维换元。
- 2024 Q22：`assets06/exam24-06.jpg`（同一原上传卷）。独立 X_i∼U[0,θ], θ>0，U=X_(n)/θ，n为正整数。CDF在(0,1)为 u^n，区间外0/1；密度 n u^(n−1)。实际按符号指数规则计算 E(U^k)=n/(n+k)，k=0,…,12。E(cX_(n))=θ 给 c=(n+1)/n；标准化 MSE h/θ²=c²n/(n+2)−2cn/(n+1)+1；实际对 c 求导并核验用户化简、驻点 c=(n+2)/(n+1)；二阶导 2n/(n+2)>0，故唯一全局最小。该参数幂运算限标准化最大值，不是通用符号指数引擎。

定义域核验：输入有理式逐个检查分母，用正变量及 n=1+w,w≥0 的同号系数充分条件保证非零。不能证明的分母会被拒绝，即使可能实际处处非零；不接受通过相消隐藏的零分母。测试 n=1、v=1 等漏洞。其余题目和原上传卷差异处理均未变动。
