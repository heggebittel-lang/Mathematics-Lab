# V2.1 原卷核验
题面依据：用户提供的《03.2010-2022考研数学三真题.pdf》，原题图已随 V1.6 导入 assets16。逐题查看 2022-18.jpg、2022-19.jpg、2021-17.jpg、2021-19.jpg、2021-22.jpg，不使用网络其他卷种题面。原题图、原纸笔答案与解析保留。
- 2022 Q18：生产函数 12x^(1/2)y^(1/6)，价格 1160−1.5Q，投入价格6、8。固定产量，y=(Q/12)^6/x³，成本严格凸且两端发散。边际产量比等于价格比，x=4y，Q=24y^(2/3)，C=32(Q/24)^(3/2)。令 t=√(Q/24)，利润导数 1160−72t²−2t，正根4，Q=384。
- 2022 Q19：右半片 r≤2，0≤θ≤π/2；左半片 r≤2/(sinθ−cosθ)，π/2≤θ≤π。被积函数乘雅可比 r(1−sin2θ)。两片分别 π−2、π，合计2π−2。
- 2021 Q19：0≤θ≤π/4、0≤r≤1，令 t=1+sin2θ 后角积分得 r(e^(2r²)−e^(r²))/2，径向积分为(e−1)²/8。
- 2021 Q22：U均匀于(0,2)，X=min(U,2−U)，Y=2−X。F_X(x)=x (0<x<1)，F_Z(z)=1−2/(z+1) (z>1)，支持集外按CDF性质延拓；导数给密度。期望 ∫₀¹ x/(2−x)dx=2ln2−1。
- 2021 Q17：左右极限分别 −aπ/2+e⁻¹、aπ/2+e，两者相等得到 a=(e⁻¹−e)/π。
