# V1.8 数学三原卷核验
所有五题以用户上传《03.2010-2022考研数学三真题.pdf》对应原卷（科目303）及包内题图为依据，不使用其他卷种题面。物理页码：2022 Q16 第3页，2021 Q7 第7页，2020 Q7 第10页、Q14 第11页，2019 Q2 第13页。对应裁图 `assets16/2022-16.jpg`、`2021-07.jpg`、`2020-07.jpg`、`2020-14.jpg`、`2019-02.jpg`。本次未联网取答案。
- 2022 Q16：P(BC)=1/9，P(B∪C)=5/9，A与B∪C互斥，P(A∪B∪C)=8/9，条件概率5/8。
- 2020 Q7：P(AB)=0只推出P(ABC)=0，不能推出AB为空集。恰一概率=3/4−2(1/12+1/12)+0=5/12，D。
- 2020 Q14：P(X=k)=2^(−k)，k从1开始；按模3分组，余数0首项1/8，1首项1/2，2首项1/4；公比1/8，概率1/7、4/7、2/7，期望8/7。
- 2019 Q2：f'=5(x−1)(x+1)(x²+1)，f(−1)=k+4、f(1)=k−4；极大值正且极小值负才有三个不同实根，所以D。
- 2021 Q7：C选项P、Q为三角且对角元非零；PA三行(1,0,−1)、(0,1,−3)、(0,0,0)，PAQ=diag(1,1,0)。学生自行选择选项，程序执行矩阵乘法和对角性核验。
