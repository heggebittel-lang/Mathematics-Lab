# 自备本地资料（可选）

公开版不提供原卷扫描或资料 PDF。使用个人合法持有的资料时，可以直接对照纸质或电子原卷，数学工作台仍可运行。如果持有原完整离线包，可在自己电脑上将其中的 `assets06/`、`assets16/`、`resources/` 合并到公开版同名目录，然后点击顶部「本地资料：关闭」切换为开启。不要上传这些文件到公开仓库。

旧版约定：`assets16/YYYY-NN.jpg` 为题目裁图，`assets06/` 为原卷和资料页图，`resources/` 为来源文件。各题的具体源文件和页码可参考代码中的题目数据及本目录的来源说明。没有完整包的用户不需要创建这些文件，直接对照自备试卷即可。
