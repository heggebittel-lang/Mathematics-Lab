# V3.0 数学三原卷核验
仅使用包内原卷裁图 assets16/2021-05.jpg、2019-07.jpg、2020-05.jpg、2020-01.jpg、2019-15.jpg，逐图核对题面。未采用其他卷种或网络题面。

- 2021 Q5：令 u=x₁+x₂，v=x₂+x₃，则 x₃−x₁=v−u，原二次型=2uv=[(u+v)²−(u−v)²]/2。u,v 独立，可扩充为三维坐标基；正负惯性指数各1，选B。实际多项式回代及平方形式恒等核验，不强制特定线性形式。
- 2019 Q7：A=AB ⊔ A非B，B=AB ⊔ B非A。差等于 P(A非B)−P(B非A)，故原题充要条件为 C。内核按四个互斥基本区域的位集合检查分解及系数相消，适用于此形式的两事件代数。
- 2020 Q5：|A|=0、A₁₂≠0，四阶矩阵秩3；伴随矩阵秩1，零空间维数3。A*A=0，A 每一列均为解。非零余子式删去第1行第2列，保留列1,3,4，故这三列独立且为基础解系，选C。允许排列不同的三列。
- 2020 Q1：有限比值使 f(x)−a→0。t=(f(x)−a)/2，sin f(x)−sin a=2 cos((f(x)+a)/2) sin t。将 sin t/t 在0处连续延拓为1，原比值为该因子、余弦及题给比值之积，极限 b cos a，选B。无需假设 f(a)=a。属于结构化极限判断核验，非任意极限自动求解。
- 2019 Q15：x>0 时 x^(2x)=exp(2x ln x)，导数2x^(2x)(ln x+1)；x<0 时导数(1+x)e^x。0处连续，左差商→1，右差商∼2 ln x→−∞，不可导。驻点−1、e⁻¹处负变正，局部极小值分别为1−e⁻¹、e^(−2/e)；0处左增右减，局部极大值1。实际使用通用求导；分段差商和极值分类为本题结构化核验，极值函数值按原式代入呈现。未实现任意分段函数自动极值求解。
