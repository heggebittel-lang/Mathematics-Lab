# V2.6 原卷与数学核验
以用户上传的数学三原卷为准，直接核对 `assets16/2021-01.jpg`、`2021-02.jpg`、`2022-13.jpg`、`2019-06.jpg`、`2020-09.jpg`。原始PDF仍位于 resources。未采用网上题面或答案。

- 2021 Q1：e^(t³)−1=t³+o(t³)。积分至 x²（非负），得到x⁸/4+o(x⁸)；相对x⁷比值趋0，高阶，C。余项传播有实际多项式系数运算。
- 2021 Q2：e^x−1=x+x²/2+o(x²)；约分后1+x/2+o(x)。与f(0)=1一致；差商极限1/2，D。
- 2022 Q13：e^(sin x)+e^(−sin x)以2π为周期；0点Taylor展开为2+x²+o(x³)，第三阶系数0，乘3!得0。亦可直接由偶函数的三阶导为奇函数推出。
- 2019 Q6：Av=λv，代入A²+A=2E得λ²+λ−2=0；实对称可正交对角化。λ=1,−2，若正根重数k，则1^k(−2)^(3−k)=4，k=1。规范形y₁²−y₂²−y₃²，C。
- 2020 Q9：u=xy+sin(x+y)，uₓ=y+cos(x+y)，uᵧ=x+cos(x+y)。在(0,π)分别为u=0、uₓ=π−1、uᵧ=−1，外层因子1/(1+u²)=1，全微分(π−1)dx−dy。
