- 2020 Q12（合集物理页11）：0≤x≤1，x/2≤y≤1/(1+x²)，绕 y 轴。V=2π∫x(1/(1+x²)−x/2)dx=π[ln(1+x²)−x³/3]₀¹=π(ln2−1/3)。
- 2020 Q20（页11）：A=[[1,−2],[−2,4]]，G=[[a,2],[2,b]]，a≥b。迹5，行列式0，故 a+b=5、ab=4；a=4,b=1。原平方(x₁−2x₂)²，取x₁=y₂,x₂=−y₁；Q=[[0,1],[−1,0]]，直接精确验证QᵀQ=E、QᵀAQ=G。−Q也成立，不强迫固定矩阵。
- 2020 Q21（页11）：α≠0且非A特征向量，若与Aα线性相关即矛盾，故P可逆（纸笔证明）。由 A²α=6α−Aα，AP 的两列基坐标分别(0,1)、(6,−1)，B=P⁻¹AP=[[0,6],[1,−1]]。特征多项式λ²+λ−6，根2、−3，相似于实对角矩阵。
- 2020 Q22（页11—12）：单位上半圆均匀，极角θ均匀于(0,π)。Z₁=1 对应θ∈(0,π/4)，Z₂=1 对应θ∈(0,3π/4)，端点概率为0。按0、1排序联合表为[[1/4,1/2],[0,1/4]]，EZ₁=1/4，EZ₂=3/4，EZ₁Z₂=1/4，Cov=1/16，两个方差3/16，ρ=1/3。
- 2019 Q14（页14）：f=x/2（0<x<2），EX=∫₀²x²/2 dx=4/3。F=x²/4（内部），其他按CDF延拓。连续CDF意味着F(X)~U(0,1)，所以 P(F(X)>EX−1)=2/3。
