# V3.9 原卷核验与实现边界

原上传2023数学三真题.pdf第2页，包内原卷图 assets06/exam23-02.jpg，核对Q1—4。原上传2025考研数学（三）真题.pdf首张题面，包内 assets06/exam25-02.jpg，核对Q3。新上传 all-math3-solutions-20261108.pdf PDF第563页的2025 Q3补充k>−1，原卷未给出。本版保留原卷，额外明示完整实数级数须有定义；任意实k的尾部最终有定义。

- 2023 Q1：固定y=1，两侧解析切片 ln(1±h sin1) 在0的导数为±sin1；固定x=0，ln y导数在1为1。左、右结果不相等，选A。实际求导及代入，sin1>0及绝对值分支由规则核验。
- 2023 Q2：左候选 ln(sqrt(1+x²)+sx)+C（s=±1）实际求导，根式作为正符号核验有理恒等式。右候选限 x、sin x、cos x 的有理系数多项式组合，实际求导及同类项合并。左、右在0的值须相等，左右导数趋于1，故连接后可导。原卷D满足；允许其他匹配常数。非多项式或无法核验的等价形式可能被拒绝。
- 2023 Q3：按所有解在全实轴有界解释；若仅存在一个有界解，零解总有界。四个参数选项的根的和、积与实部判据逐项核验，纯虚共轭不同根对应C。不是任意ODE求解器。
- 2023 Q4：a<b，且两级数收敛，故d=b−a非负、绝对收敛。用户输入两个方向的线性表达式，精确恒等核验后运用三角不等式。A。敛散证明采用结构化定理规则而非自动证明。
- 2025 Q3：令t=1/n，实际展开 ln(1+u)（1至4阶）并代u=kt²，用稀疏多项式实际相减得到 t+O(t²)。由交错调和级数收敛、对数项绝对收敛及绝对值主项等价于1/n，得到条件收敛。k>−1时全级数有实数定义，其他k只讨论有定义尾级数，选B按有定义理解。
